# push、pull、diff 的路径范围与空目录

自 v1.6.0 起，正式命令 `lansync` 支持以下路径范围和空目录行为。

## diff 比较什么

`diff` 回答一个问题：**在指定范围内，两端可参与同步的文件，在相同相对路径上是否具有相同内容？** 不带参数时，范围是当前目录及其子树。带多个路径时，建议取所有参数匹配范围的并集，同一路径只比较一次。两端使用相同的相对路径和选择条件，各自的清单仍受忽略规则过滤。

比较应覆盖两端文件路径的并集。只有本地有的记为 `local-only`，只有远端有的记为 `server-only`，两端都有但内容哈希不同的记为 `modified`。内容相同只计入一致数量，修改时间不同不构成差异。沿用按路径排序的输出、`--json` 及退出码：0 表示范围内文件一致，1 表示存在差异，2 表示无法完成比较。

例如远端独有 `src/old.js` 时，`diff src` 应报告它。接下来执行 `pull src` 会下载它，执行 `push src` 则保留它。差异描述两端的状态，具体动作取决于同步方向和删除选项。对两端都有的文件，push、pull 和 diff 都按清单中的内容哈希判断是否一致。

## 三个命令如何选路径

| 命令 | 用于确认选择范围的清单 | 显式指定路径后的动作 |
| --- | --- | --- |
| push | 本地 | 上传选中的新增或变化文件，保留远端独有文件 |
| pull | 远端 | 下载选中的新增或变化文件，保留本地独有文件 |
| diff | 本地与远端的并集 | 只读比较选中的路径 |

现有 CLI 只取第一个位置参数。建议接受多个文件、目录和 glob，先解析全部参数，再执行一次操作。目录按路径边界递归匹配，带点的目录名如 `docs/v1.0` 也应生效。引用的 glob 由 lansync 按对应清单匹配；未引用的 glob 如果已被 shell 展开，就逐一处理收到的路径。无参数 push/pull 保留当前目录的镜像行为，`--no-delete` 保留目标端独有文件。

**无文件可比与路径拼错要区分。** 建议已确认存在的目录即使为空或只含忽略文件，也算有效范围。显式路径在对应源端不存在（diff 为两端都不存在），或显式 glob 在对应清单中没有匹配时，应标明该参数并报错。多个参数里只要有一个无效，先报错再退出，不开始传输。无参数 diff 遇到两份空清单仍返回 0。当前远端对应工作子目录不存在时，diff 按空远端清单比较，pull 则拒绝镜像，以免误删本地文件。

## 空目录的生命周期

目前两端扫描都只把普通文件列入清单。空目录不会单独传输，也不会单独形成差异。向对端写入文件时才创建所需的父目录。因此，一端有空目录、另一端没有，只要范围内文件一致，diff 就应返回 0。

| 场景 | v1.5.0 实现 | 建议 |
| --- | --- | --- |
| push 删除了远端最后一个文件 | 服务端从被删文件的父目录向上尝试删除空目录，遇到非空目录或服务端根即停止 | 保留按实际删除路径修剪的行为。对子目录镜像，建议最多修剪到本次同步范围根，保留该根目录 |
| pull 删除了本地最后一个文件 | 同步结束后递归扫描整个当前目录，删除所有空子目录 | 仅在文件删除成功后向上修剪，保留本次同步范围根。原先就空、与本次删除无关的目录保留 |
| 显式指定文件、目录，或使用 `--no-delete` | 两端都禁用文件删除，但 pull 仍执行整棵目录的清理 | 未删除文件就不修剪目录。只下载一个文件也不应清掉旁边的空目录 |
| diff | 读取清单并比较文件 | 全程只读，保留两端目录结构 |

试用版清单额外返回目录路径，用于识别空目录；旧服务端只能从文件路径推断非空目录。子目录镜像删除前，客户端检查服务端是否支持修剪边界，旧服务端需升级或使用 `--no-delete`。删除接口校验文件位于指定范围内，再从被删文件的父目录向上修剪。

## 验收样例

| 初始条件与命令 | 预期结果 |
| --- | --- |
| 本地有两个新文件 `xxx1`、`xxx2`，执行 `push xxx*` | 两者都上传；重复选中任一文件也只上传一次 |
| 仅远端有 `a.csv`、`b.csv`，执行 `pull '*.csv'` | 两者都下载；旁边原有的本地空目录保留 |
| 本地有空目录 `cache/`，远端没有，执行 `diff cache/` | 退出 0，无文件差异；远端无需创建目录 |
| 两端都没有 `cahce/`，执行 `diff cahce/` | 报出该路径，退出 2 |
| 仅远端有 `src/z.js`，执行 `diff src zzz`，两端都没有 `zzz` | 指出无效参数 `zzz`，退出 2；单独执行 `diff src` 应报告 `server-only`，退出 1 |
| 在 `src/` 内执行无参数镜像，源端的 `src/sub/last.js` 已删除 | 删除目标端文件，修剪变空的 `sub/`，保留 `src/`。若 `sub/` 仍含忽略文件则保留它 |
